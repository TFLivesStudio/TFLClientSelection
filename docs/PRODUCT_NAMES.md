# Nombres del ecosistema TFL

| Nombre | Qué es | Uso |
| --- | --- | --- |
| **TFL Client** | El launcher de TFLives. | Instala, actualiza, organiza y abre instancias de Minecraft. Se escribe con espacio. |
| **TFL Selection** | La biblioteca donde TFLives publica sus propios clientes modificados de Minecraft. | Desde el launcher eliges el cliente y la versión que quieres instalar. |
| **TFLClient** | El cliente modificado de Minecraft. | Es la experiencia que utilizas dentro del juego; se obtiene en TFL Selection. Se escribe sin espacio. |
| **TFL Core** | El componente que impulsa funciones dentro de TFLClient. | Describe el componente, no sustituye el nombre del cliente. |

Una frase para explicarlo: **«Abre el launcher TFL Client, entra en la biblioteca
TFL Selection e instala TFLClient para tu versión de Minecraft».**

## Términos de uso

- **Instancia:** una instalación con sus propios archivos, ajustes y mundos.
- **Biblioteca del launcher:** organiza las instancias que ya tienes instaladas.
- **TFL Selection:** biblioteca de clientes publicados por TFLives, distinta de la
  lista de instancias instaladas.
- **Modpack:** paquete de mods y configuración. No es el nombre de la biblioteca.
- **Módulo:** función configurable dentro del cliente; depende de su versión.
- **Canal:** estable, beta o desarrollo. El launcher y el cliente tienen versiones
  y canales independientes.

## Aplicación de los nombres

Usa TFL Selection en la navegación de la biblioteca. Los botones para instalar o
abrir un cliente deben identificar TFLClient, por ejemplo «Instalar TFLClient
1.8.9». El número de Minecraft y el número de release del cliente se muestran por
separado cuando ambos sean necesarios.

Aplica esta distinción a textos de interfaz, traducciones, documentación, notas de
publicación y metadatos. La guía para jugadores está en
[el glosario de la web oficial](https://launcher.tflives.com/ayuda/glosario).

Los nombres de repositorios, paquetes, rutas, IDs, formatos y claves guardadas
pueden conservar nombres técnicos anteriores. No se cambian por una corrección
editorial. Los catálogos y manifiestos firmados conservan sus bytes originales;
los consumidores normalizan las etiquetas antiguas al mostrarlas y el publicador
utiliza los nombres correctos en las próximas generaciones firmadas.

Los archivos de evidencia y documentos históricos originales conservan el nombre
usado cuando se crearon; no definen la terminología vigente. Las notas públicas
revisadas sí utilizan los nombres actuales sin atribuir funciones nuevas a una
versión anterior.
